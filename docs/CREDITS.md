# XenoRushGP – SFX candidates credits

All files below are **CC0 1.0 (public domain)**. You can use them in a commercial game with no attribution required.
(Kenney and the OpenGameArt authors say credit is appreciated but optional. A "Sound effects: Kenney.nl, rubberduck, Joth, mikeask (OpenGameArt, CC0)" line in the game's About screen is a nice gesture.)
CC0 legal text: https://creativecommons.org/publicdomain/zero/1.0/

Processing applied to all files: converted to mono, 44.1 kHz OGG Vorbis (q5), silence trimmed, short fades, peak-normalized to -1 dBFS.
Files marked "layered" combine two or three CC0 sources (a derivative mix, which CC0 allows).
Engine loops were trimmed to ~4.65 s with a 0.35 s equal-power crossfade so they loop seamlessly.
